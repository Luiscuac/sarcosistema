# RAG local de tórax Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar y verificar RAG de tórax local con evidencia exacta y abstención, sin interfaz.
**Architecture:** Dominio y puertos en imagenes; adaptadores independientes de embeddings, corpus y PostgreSQL. CLI para preparación, ingesta y consulta. Generación extractiva estructurada predeterminada; Ollama únicamente si la medición permite usarlo de forma segura.
**Tech Stack:** Python 3.12, SQLAlchemy/asyncpg, PostgreSQL16/pgvector, embeddings E5 CPU opcionales, Alembic, pytest.
**Spec:** `docs/superpowers/specs/2026-11-03-rag-torax-design.md`

## Global Constraints
- Sin interfaz, publicación clínica, proveedores externos en runtime, commits ni push.
- Conservar cambios locales, datos y volúmenes; migración exclusivamente incremental.
- Fuentes con licencia comprobada, originales locales, hashes y citas literales verificables.
- Embeddings preparados explícitamente; CPU, 384 dimensiones y prefijos query/passage E5.
- Ausencia de evidencia devuelve información insuficiente; puntuaciones no son certeza clínica.

## Review Focus
- Negaciones y consultas ajenas: no producir afirmaciones clínicas por coincidencias parciales.
- Documentos modificados o modelos incompatibles: rechazar antes de indexar/consultar.
- Inyección en consulta/documentos: texto tratado como datos, SQL parametrizado, sin ejecutar instrucciones.
- Reingesta y cambios de corpus: idempotencia y referencias sin fragmentos obsoletos.
- Falta de RAM, servicio o pesos: error claro o fallback, nunca descarga automática.

## Revisión del plan
Cada requisito del diseño se asigna a una tarea; las cinco clases de fallo figuran en pruebas de contratos, persistencia y consulta. La elección final del corpus y versión de dependencias requiere verificar disponibilidad y permisos, no asumirlos. No hay autorización para commits ni eliminación de recursos existentes.
